# LENA HOME — Захиалгат хөшигний платформ ба 3D Хөшигний студи

Улаанбаатар хотын LENA HOME компанийн премиум захиалгат хөшигний вэб платформ.
Монгол хэл дээр, даавууны бодит каталог, 3D хөшигний студи, ухаалаг хэмжилт,
үнийн тооцоолол, зөвлөгөөний хүсэлт, админ удирдлага бүгд нэг системд.

## Технологи

| Хэсэг | Технологи |
|---|---|
| Framework | Next.js 15 (App Router, React 19, TypeScript) |
| Загвар | Tailwind CSS 4 |
| 3D | Three.js + React Three Fiber + drei |
| Өгөгдлийн сан | SQLite (`node:sqlite`, сервер талд, `data/lena.db`) |
| Зураг хадгалалт | `data/uploads` + `/api/uploads/*` |
| Нэвтрэлт | scrypt нууц үг + HMAC-гаар гарын үсэг зурсан httpOnly cookie |

Гадаад үйлчилгээний түлхүүргүйгээр бүрэн ажиллана. AI Vision (сонголтоор) нь
`OPENAI_API_KEY` тохируулсан үед идэвхждэг.

## Ажиллуулах

```bash
npm install
cp .env.example .env.local   # утгуудыг тохируулна
npm run dev                  # http://localhost:3000
```

Эхний ажиллуулалтад өгөгдлийн сан үүсч, 10 материал, 273 өнгөний код
автоматаар бөглөгдөнө.

Админ: `/admin` — `.env.local` дахь `ADMIN_USERNAME` / `ADMIN_PASSWORD`
(анхдагч `admin` / `LenaHome2026`). **Үүнийг заавал солино уу.**

Production:

```bash
npm run build
npm start
```

## Гол боломжууд

- **Нүүр, коллекц, материал, үйлчилгээ, бидний тухай, холбоо барих** — бүх текст монголоор.
- **Даавууны каталог** — 10 материал, 273 өнгөний код; код/нэр/материалаар хайх,
  өнгө, интерьерийн хэв маяг, үнээр шүүх.
- **3D Хөшигний студи** (`/studio`) — 8 өрөө, 9 хөшигний загвар, материал ба өнгө
  шууд солигдоно, 5 гэрэлтүүлгийн горим, камерын 4 өнцөг, хэмжээ ба үнийн шууд тооцоо.
- **Ухаалаг хэмжилт** (`/services#measure`) — даавууны зарцуулалт, оёдол, дагалдах
  хэрэгсэл, зам, угсралт, хүргэлтийн урьдчилсан үнэ.
- **AI COLOR MATCH** (`/ai-match`) — өрөөний зурагнаас өнгө ялгаж, бодит каталогийн
  өнгөнүүдтэй ΔE-ээр харьцуулна.
- **Дизайн хадгалах ба хуваалцах** — 3D зургийн хамт серверт хадгалж, `/design/<id>`
  холбоосоор хуваалцана.
- **Зөвлөгөөний хүсэлт** — өгөгдлийн санд хадгалагдаж, админаас төлөв өөрчилнө.
- **Админ** — материал/өнгө CRUD, swatch зураг upload, үнийн тариф, хүсэлт, дизайн.

## Өнгөний үнэн бодит байдлын дүрэм

Үйлдвэрлэгчийн кодуудыг яг хэвээр хадгалсан. Өнгөний нэрийг **зөвхөн код дотор
бичигдсэн өнгөний үгнээс** (жишээ нь `VR-10346-SIYAH` → SIYAH = хар) гаргасан бөгөөд
эдгээр нь ойролцоо тон гэж `~` тэмдгээр тэмдэглэгдэнэ. Код дотор өнгөний нэр
байхгүй бол систем өнгө зохиохгүй — `Swatch шаардлагатай` гэж харуулж, админ бодит
swatch зургийг upload хийнэ. Албан ёсны баталгаажсан HEX утга зохиохгүй.

## Файлын бүтэц

```
app/                    Маршрутууд (page, api)
components/             UI, 3D, форм, админ
lib/                    Каталог, өнгөний шинжлэх ухаан, тооцоо, DB, auth
data/                   SQLite DB + uploads (git-д орохгүй)
```

## Тайлбар

- 3D студи WebGL дэмждэггүй төхөөрөмжид статик урьдчилсан харагдац руу шилжиж,
  хэмжээ/үнэ/зөвлөгөө бүрэн ажиллана.
- Бүх тооцоо нь **урьдчилсан** бөгөөд мэргэжлийн хэмжилтээр баталгаажна.
- Сайтын зурагнууд нь SVG-ээр процедураар үүсгэгдсэн тул гадаад зураг хүлээхгүй,
  хурдан ачаалагдана.
